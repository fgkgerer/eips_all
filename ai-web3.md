# AI + Web3 — ERC/EIP 标准应用指南

## 领域概述

AI + Web3 是区块链最前沿的应用方向。AI Agent（智能代理）在链上自主执行交易、管理资产、调用服务，需要一个完整的信任和经济基础设施。ERC-8004、X402 和 ERC-8183 分别解决了**信任（Trust）、支付（Payment）、结算（Settlement）**三大核心问题，构成了 AI Agent 经济的完整协议栈。

## 标准总览

| 标准       | 简称     | 在 AI+Web3 中的角色                              | 详细文档 |
| ---------- | -------- | ------------------------------------------------ | -------- |
| **ERC-8004** | 信任协议 | Agent 身份注册、声誉评价、工作验证               | [ERC-8004.md](ERC-8004.md) |
| **X402**     | 支付协议 | Agent 之间的即时支付——HTTP 402 "Payment Required" | [X402.md](X402.md) |
| **ERC-8183** | 结算标准 | 复杂任务的托管式雇佣→交付→判定→结算              | [ERC-8183.md](ERC-8183.md) |

## 为什么 AI Agent 需要 Web3 标准？

### AI Agent 面临的信任问题

当一个 AI Agent（如 DeFi 策略优化器）想要使用另一个 Agent（如市场数据分析师）的服务时：

```
传统互联网（Web2）:            Web3 方案:

1. 注册 OpenAI API          1. ERC-8004: 链上发现 Agent 身份
2. 绑定信用卡               2. ERC-8004: 查看链上声誉评分
3. 获取 API Key             3. ERC-8183: 创建托管 Job
4. 设置月限额               4. X402: 按需支付服务费
5. 监控账单                 5. ERC-8183: Evaluator 自动判定
6. 数据隐私担忧             6. 无需信任任何平台

问题: 集中化、需信任、       优势: 去中心化、信任最小化、
     每个服务都要注册             零注册、自主运行
```

## 标准详解

### ERC-8004：AI Agent 的链上身份证

```
"在让 AI Agent 互相交易之前，它们需要知道对方是谁、是否可靠。"

ERC-8004 的三层信任体系:

第一层: 身份（Identity）
  - 每个 Agent = 一个 ERC-721 NFT
  - agentURI 描述能力: A2A 端点、MCP 端点、支持的信任模型
  - 可转让、可验证、抗审查

第二层: 声誉（Reputation）
  - 标准化的反馈系统（评分、成功率、响应时间）
  - 不能给自己评分（防刷分）
  - 声誉数据公开透明，链上可查

第三层: 验证（Validation）
  - 加密经济安全: 质押 + 重执行 + 罚没
  - zkML: 零知识证明 AI 推理正确
  - TEE 认证: 硬件证明执行环境安全
```

### X402：AI Agent 间支付的 HTTP 标准

X402 的优雅之处在于：将支付融入 HTTP 协议本身。

```
传统 API 调用:                  X402 API 调用:

GET /analyze?token=ETH          GET /analyze?token=ETH
Authorization: Bearer sk-xxx    (无 API Key)
                                →
                                402 Payment Required
                                PAYMENT-REQUIRED: {
                                  网络: Base
                                  代币: USDC
                                  金额: 0.01 USDC
                                }
                                ←
GET /analyze?token=ETH
PAYMENT-SIGNATURE: 0x...        →
                                200 OK
                                {分析结果}
                                ←

对比:
  传统: 需要 API Key + 月结账单
  X402: 零注册 + 按需支付 + 即时结算
```

**已处理超过 1 亿笔支付**，Stripe 在 2026 年 2 月正式集成。

### ERC-8183：去中心化的 Agent "Upwork"

当任务不是一次 API 调用可以完成时（可能需要数小时或数天），ERC-8183 提供完整的任务生命周期管理：

```
Client Agent                     ERC-8183 合约                   Provider Agent
     │                                │                               │
     │ 1. createJob(任务规格, 100 USDC)│                               │
     │───────────────────────────────>│                               │
     │   资金锁定在托管合约中           │                               │
     │                                │                               │
     │                                │ 2. Provider 投标/领取          │
     │                                │<──────────────────────────────│
     │                                │                               │
     │                                │ 3. 提交工作结果               │
     │                                │<──────────────────────────────│
     │                                │                               │
     │                                │ 4. Evaluator 判定            │
     │                                │    complete() or reject()    │
     │                                │                               │
     │ 5. 获得结果                    │ 6. Provider 获得 99 USDC   │
     │                                │    协议费 0.5 USDC          │
     │                                │    Evaluator 费 0.5 USDC    │
```

**Evaluator 的可组合设计**：
- AI Agent 自动评估常见任务
- ZK 验证器验证可证明的计算
- DAO 多签处理主观判定
- 质押验证者网络提供加密经济安全

## 当前生态状态

| 标准       | 状态       | 关键进展                                                        |
| ---------- | ---------- | --------------------------------------------------------------- |
| ERC-8004   | Draft      | MetaMask + Ethereum Foundation + Google + Coinbase 联合推动     |
| X402       | 非官方协议  | Stripe 集成、1 亿+ 支付处理、多链支持                             |
| ERC-8183   | Draft      | Ethereum Foundation dAI + Virtuals Protocol, Demsys 参考实现    |

**Agent 数量增长**：从 2025 年中的 337 个注册 Agent 增长到 2026 年的 ~130,000 个，AI Agent 经济正在爆发。

## 学习路径建议

1. **先学 ERC-8004** — 理解 Agent 身份和声誉体系（信任是所有交互的基础）
2. **再学 X402** — 理解即时支付如何让 Agent 按需消费（HTTP 开发者熟悉）
3. **最后学 ERC-8183** — 理解复杂任务的托管结算（最完整的经济模型）
4. **关注扩展标准** — ERC-8196（Agent 钱包）、ERC-8126（Agent 验证）
